# java-basics

Java 21 setup test project using IntelliJ IDEA and Eclipse Temurin on macOS.

## Purpose

This repository documents a small Java learning setup used to verify that:

- IntelliJ IDEA opens the project correctly
- Eclipse Temurin 21 LTS is used as the project JDK
- Java source files in `src/` compile and run successfully
- local IDE and build output files stay out of Git

## Environment

- macOS Sonoma on Intel Mac
- IntelliJ IDEA
- Eclipse Temurin 21 LTS
- Java 21
- Git / GitHub

## Project structure

```text
java-basics/
├── src/
│   ├── HelloWorld.java
│   └── Main.java
├── .gitignore
├── LICENSE
└── README.md
```

## Run

Open the project in IntelliJ IDEA and run `HelloWorld.main()` or `Main.main()`.

Example output:

```text
Java 21 läuft sauber in IntelliJ.
```

## Notes

This is a small learning and setup verification project. It is intentionally simple and focuses on a clean Java 21 development workflow.
